# Proyek Pemrograman Mobile

## Deskripsi

Aplikasi latihan untuk memenuhi tugas praktikum pemrograman mobile pada pertemuan 1.

## Tujuan

Proyek ini bertujuan untuk mempelajari dasar pengembangan aplikasi mobile menggunakan Flutter serta memahami penggunaan Git dan GitHub dalam pengelolaan proyek.

## Rencana Fitur

1. Pemesanan transportasi seperti GrabBike dan GrabCar.
2. Pemesanan makanan dan minuman melalui GrabFood.
3. Pengiriman barang melalui GrabExpress.

## Cara Menjalankan

Pastikan Flutter dan Android SDK sudah terpasang dan telah dikonfigurasi pada perangkat.

Buka terminal pada folder utama proyek, kemudian jalankan perintah berikut:

```bash
flutter pub get
flutter run
```
